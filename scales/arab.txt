# Ratios from rast: zirguleh 16/15, dugah 9/8, kurdi 6/5, segah 102/83, nimbuselik 5/4,
#   chahargah 4/3, hijaz 45/32, tikhijaz 729/512, nawa 3/2, hisar 189/118, husayni 27/16,
#   ajam 883/490, awj 400/217, nimmahur 15/8.
#   awj is also segah x 3/2 (153/83) to within 0.1 cent; the pure fourth or fifth above a named note is
#   used below wherever a maqam needs a half-flat the list does not name.
# Every value is written as a ratio from RAST (the maqam's note names are in the comment).
# `from <ratio>` names the maqam's own tonic: the generator divides every value by it and
# octave-reduces, so a maqam on dugah is relative to dugah. The first value is the tonic.
